# 成本與成功率口徑

## Token

任務總 Token = 所有模型呼叫的輸入 Token + 輸出 Token，包含失敗與重試。依供應商 usage 定義記錄快取與推理 Token；若已包含於輸入或輸出，不得再次加總。不同 tokenizer 的 Token 數不可當作等價工作量。

Token 數與費用分開記錄：同樣 Token 數在不同模型、快取或批次計費下可能價格不同。不提供未核實的即時價格。

## TTC

TTC = 模型費 + 檢索費 + 工具/API 費 + 自有運算費 + 人工成本 + 經定義的時間成本。

各項互斥：已含在 API 帳單的託管運算不再計自有運算；重試歸入各對應成本項；人工工作時間已計人工費，不再計相同時間損失。等待時間若無合理金額換算，獨立列秒數，不硬加進 TTC。

## 成功率與每件成功任務成本

TSR = 通過預定驗收的任務數 / 納入評估的任務總數。

每件成功任務成本 = 同一評估批次所有任務成本（含失敗）/ 成功任務數。

成功數為零時成本指標記為不可計算，不能填零。單次成功與否不是成功率；比較路徑須使用相同任務集、驗收標準、權限與價格時間點。

## 模擬算例

同一批 10 個任務，A 路徑成本合計 100 元、8 件通過，TSR 為 80%，每件成功成本 12.5 元；B 路徑合計 120 元、10 件通過，TSR 為 100%，每件成功成本 12 元。若目標成功率 90%，A 不符合門檻。以上數字純示意，不代表模型實測或市場價格。

## 紀錄表

templates/task-cost.csv 每列是一個任務的最終結算，彙總其全部呼叫，attempt_count 記實際嘗試數。passed 為 true 或 false；空欄代表尚未填寫，不代表零。幣別需一致才可加總。自有運算、人工與時間換算依組織口徑填入 notes。

模型費、工具費與成功率應取自可核對的 usage、帳單或驗收證據。成本最小化是目標，不是本套件已實現的自動演算法。
